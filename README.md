# 写真つぶつぶアートくん

「写真つぶつぶアートくん」は、元画像と複数の素材写真からフォトモザイク画像を作る静的Webアプリです。

画像処理はすべてブラウザ内のCanvas APIで行います。AI、バックエンド、外部ライブラリは使っていません。

## 使い方

1. `index.html` をブラウザで開きます。
2. 「元画像」から、大きな絵として見せたい写真を1枚選びます。
3. 「素材写真」から、小さなタイルとして使う写真を複数選びます。
4. タイルサイズ、元画像の重ね具合、出力サイズを選びます。
5. 素材の使い方を選びます。少ない枚数をしっかり見せたい場合は「バランス優先」、元画像の色再現を重視したい場合は「色を優先」を選びます。
6. 「フォトモザイクを生成」を押します。
7. 生成後、「PNGで保存」から `photo-mosaic.png` として保存できます。
8. 「HTMLで保存」から、作品ページ形式の `photo-mosaic.html` として保存できます。

## 保存形式

- PNG保存：完成したフォトモザイク画像だけを保存します。
- HTML保存：完成画像、作成日時、使用素材数、タイルサイズ、元画像の重ね具合などを1つのHTMLファイルにまとめて保存します。

HTML保存では、完成画像だけをHTML内に埋め込みます。素材写真1枚1枚は埋め込まないため、ファイルサイズが大きくなりすぎにくく、会社PCやローカル環境でも扱いやすい形式です。

## 素材写真の目安

- 100枚以下：快適に処理できます
- 300枚以上：処理に少し時間がかかる場合があります
- 500枚以上：スマホでは重くなる可能性があります
- 1000枚以上：PC推奨です

初期MVPでは推奨素材写真数を300枚までとしています。選択上限は1000枚です。

## GitHub Pagesでの公開方法

1. このフォルダの `index.html`、`style.css`、`app.js`、`README.md` をGitHubリポジトリに置きます。
2. GitHubのリポジトリ画面で `Settings` を開きます。
3. `Pages` を開き、公開元のブランチとフォルダを選びます。
4. 保存すると、GitHub PagesのURLからアプリを使えます。

ビルド作業は不要です。静的ファイルを置くだけで動きます。

## プライバシー方針

- 画像はブラウザ内だけで処理されます。
- 画像をサーバーへ送信しません。
- 外部APIやAI処理は使いません。
- インターネット接続がない環境でも、ファイルを開けば基本機能を使えます。
