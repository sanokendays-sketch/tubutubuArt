# 写真つぶつぶアートくん

「写真つぶつぶアートくん」は、元画像と複数の素材写真からフォトモザイク画像を作る静的Webアプリです。

画像処理はすべてブラウザ内のCanvas APIで行います。AI、バックエンド、外部ライブラリは使っていません。

## 使い方

1. `index.html` をブラウザで開きます。
2. 「元画像」から、大きな絵として見せたい写真を1枚選びます。
3. 「素材写真」から、小さなタイルとして使う写真を複数選びます。
4. タイルサイズ、元画像の重ね具合、出力サイズ、保存品質、用途を選びます。
5. 素材の使い方を選びます。少ない枚数をしっかり見せたい場合は「バランス優先」、元画像の色再現を重視したい場合は「色を優先」を選びます。
6. 「フォトモザイクを生成」を押します。
7. 生成後、「PNGで保存」から `photo-mosaic.png` として保存できます。
8. 「作品ページとして保存（HTML）」から、閲覧用の `photo-mosaic-view-YYYYMMDD-HHMM.html` として保存できます。

## 保存形式

- PNG保存：印刷用です。完成したフォトモザイク画像だけを保存します。
- HTML保存：閲覧用です。素材写真のサムネイルとタイル配置を1つのHTMLファイルにまとめ、ブラウザで拡大しながら見られる作品ページとして保存します。

HTML保存では、使われた素材写真の表示用サムネイルをHTML内に埋め込みます。ページ内でタイルをクリックすると、その素材写真を大きく表示できます。ファイルサイズはPNGより大きくなる場合がありますが、拡大して素材写真を楽しむ用途に向いています。

HTML作品ページには、10%〜200%のズーム、全体に合わせる表示、全体を見るモード、写真を見るモードがあります。小さく表示して全体像を確認し、拡大して素材写真を楽しめます。

## 保存品質

- 軽量：表示用サムネイル 256px
- 標準：表示用サムネイル 320px
- 品質優先：表示用サムネイル 512px

保存品質は素材写真の読み込み時に反映されます。品質を変えてHTML保存したい場合は、素材写真を選び直してください。

## 素材写真の目安

- 100枚以下：快適に処理できます
- 300枚以上：処理に少し時間がかかる場合があります
- 500枚以上：スマホでは重くなる可能性があります
- 1000枚以上：PC推奨です

初期MVPでは推奨素材写真数を300枚までとしています。選択上限は1000枚です。

## GitHub Pagesでの公開方法

1. このフォルダの `index.html`、`style.css`、`app.js`、`README.md` をGitHubリポジトリに置きます。
2. GitHubのリポジトリ画面で `Settings` を開きます。
3. `Pages` を開き、公開元のブランチとフォルダを選びます。
4. 保存すると、GitHub PagesのURLからアプリを使えます。

ビルド作業は不要です。静的ファイルを置くだけで動きます。

## プライバシー方針

- 画像はブラウザ内だけで処理されます。
- 画像をサーバーへ送信しません。
- 外部APIやAI処理は使いません。
- インターネット接続がない環境でも、ファイルを開けば基本機能を使えます。
